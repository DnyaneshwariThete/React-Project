# Alphabet A to Z

A simple React app that helps kids learn the English alphabet with Indian
(Hindi) pronunciation.

## Features

- Tap any letter A–Z to hear its name spoken in Hindi (`hi-IN`)
- Visual highlight for the currently active letter
- Light/dark theme toggle, remembered across visits via `localStorage`

## Getting started

```bash
npm install
npm run dev
```

## Project structure

- `src/App.tsx` — main alphabet grid and letter-speaking logic
- `src/Theme.tsx` — light/dark theme toggle
- `src/index.css` — global CSS variables and theme overrides
